# FlyMog

Telegram-бот, который оценивает фото лица «глазами» мозга дрозофилы и выдаёт
вердикт по looksmaxxing-шкале: PSL, тир, mog-процент и роаст.

> **Это развлечение.** Скор — то, как оценила бы вымышленная муха. Это не оценка
> привлекательности человека и не имеет к ней отношения. Подробности того, почему
> это шутка, лежат в [`docs/SCIENCE.md`](docs/SCIENCE.md).

## Как это устроено

```
фото → канонический кадр → гекса-глаз мухи (721 колонка)
     → оптическая доля (flyvis, замороженные веса)
     → зрительные проекционные нейроны
     → центральный мозг (коннектом FlyWire, LIF, замороженный резервуар)
     → признаки → обучаемый readout → перцентиль → PSL → тир → роаст
```

Идея — reservoir computing: настоящий коннектом мухи используется как замороженный
резервуар, обучается только лёгкий readout. Веса коннектома не трогаются.

Обучающие данные — синтетические мухи с известными параметрами, метка «красоты»
считается по параметрической формуле из литературы о выборе партнёра у дрозофил.
На людях гоняется ровно та же зрительная система и тот же readout.

## Статус

Проект на стадии **M0 (разведка)**. Работает каркас, симулятор и probe-команды;
бота ещё нет. Что именно проверено, а что нет — в
[`docs/M0_REPORT.md`](docs/M0_REPORT.md).

## Установка

Нужен Python 3.11 или 3.12 (верхняя граница — требование flyvis) и
[uv](https://docs.astral.sh/uv/).

```bash
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python -e ".[dev]"
```

Зрительный путь ставится отдельно, он тяжёлый:

```bash
uv pip install --python .venv/bin/python -e ".[flyvis]"
```

## Команды M0

```bash
flymog probe-env                  # железо и доступные бэкенды
flymog fetch-data                 # проверка и загрузка больших данных
flymog probe-inputs               # какие входные клетки есть в коннектоме
flymog probe-bridge               # сшивается ли flyvis с FlyWire
flymog bench-sim --synthetic      # скорость симуляции
flymog sweep-regime               # подбор режима работы сети
flymog m0-report                  # собрать docs/M0_REPORT.md из выводов probe
```

## Данные и лицензии

Код — MIT. Данные коннектома, предобученные веса и наборы лиц живут в `data/`,
в git не попадают и имеют **другие** лицензии. Прежде чем что-либо
перераспространять, прочитай [`docs/DATA_LICENSES.md`](docs/DATA_LICENSES.md).

## Приватность

Фото обрабатываются в памяти и удаляются сразу после ответа. В базе хранятся
только Telegram user_id, время подтверждения 18+ и счётчики лимитов.
См. [`docs/ETHICS_PRIVACY.md`](docs/ETHICS_PRIVACY.md).
